# tools/ — ferramentas de apoio

> **Criado em:** 02/11/2026 · **Última modificação:** 02/11/2026 · **Versão:** 0.1.0

Scripts de apoio ao desenvolvimento, sem código embarcado:

- `verifica_padrao.py`: verifica tamanho de função e cabeçalho de arquivo (FW-008).
- `gera_dicionario.py`: gera o dicionário de funções a partir do XML do Doxygen (FW-008 e FW-004).
- Simulador Python: broker MQTT local, comportamento offline e reconexão (fase 7).

Scripts Python rodam com o interpretador do sistema. Não incluir artefatos de build aqui.
